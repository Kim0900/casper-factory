# GEUMBOK MIRROR source provenance

EDISON wrote this synthetic-only implementation for Task #232 under MAGI event #6864.
ScreenOnAuto public descriptions supplied feature concepts. No ScreenOnAuto APK was decompiled and no code, assets, strings, signatures or resources were copied. ScreenStream was examined only for the previously approved comparison. No ScreenStream or AA Suite code is included.

The map bitmap, frame markers, UI and protocol are newly authored. Android platform APIs provide rendering, MediaCodec and networking. Bouncy Castle bcpkix/bcprov/bcutil 1.86 provide certificate construction under the Bouncy Castle licence at https://www.bouncycastle.org/licence.html. Their licence notices are retained in the dependency JAR/APK metadata. The bcpkix JAR is repackaged without the unused org.bouncycastle.est transport package and its original JAR signature metadata. Certificate APIs and cryptographic provider code keep their original names and implementations. The original and filtered JAR hashes and packaged DEX inspection are recorded by the BC audit. JUnit 4.13.2 is a build-time test dependency under EPL 1.0.

The old publicly committed signing identity is retired and removed from the current project tree. Previous signed APKs must not be used operationally. Historical copies cannot be considered secret. New APK signing uses GitHub Secrets in CI, with an expected certificate fingerprint and an explicit rejection of the old certificate. No new signing identity is generated by this repository or uploaded as a build artifact.

TLS identities remain separate ephemeral EC keys created per prepared session and never written to disk. Closing releases references to managed key objects, not a guarantee of hardware memory zeroization.
